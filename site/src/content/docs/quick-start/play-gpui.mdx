import { Steps, Aside } from '@astrojs/starlight/components';

<Steps>

1. **Download SotF Desktop**

   On macOS, install the stable desktop app from the [App Store](https://apps.apple.com/ch/app/sound-of-the-future/id6754237332). On Linux, grab the latest `.AppImage` from [GitHub Releases](https://github.com/pierreaubert/sotf/releases). Beta desktop builds are also published on GitHub Releases.

2. **Launch and add your music**

   Open the app. Go to **Settings** and add your music directory. SotF scans in the background.

3. **Browse and play**

   Click any album in the Library view, then click a track to start playback.

   | Key | Action |
   |-----|--------|
   | `n` or `>` | Next track |
   | `b` or `<` | Previous track |
   | `+` / `-` | Volume up / down |
   | `/` | Search |
   | `?` | Help |

4. **Done!**

   Explore the Studio tab to add plugins like EQ, compression, or surround upmixing.

</Steps>

<Aside type="tip">
Press `F1` on any screen for contextual help explaining what that screen does.
</Aside>
