import { Steps, Aside } from '@astrojs/starlight/components';

<Steps>

1. **Open the Headphone EQ screen**

   - **TUI**: Press the key to navigate to Configure, then select Headphone EQ.
   - **Desktop**: Click the Headphone EQ tab.

2. **Search for your headphone model**

   Type your headphone name (e.g., "Beyerdynamic DT1990") and select it from the list.

3. **Click Optimize**

   SotF calculates the optimal EQ filters targeting the Harman curve. This takes a few seconds.

4. **Apply to your plugin chain**

   Click **Apply** to load the filters into the EQ plugin. The difference is immediate.

</Steps>

<Aside type="note">
The Harman target curve is backed by decades of listening preference research. Most people prefer it, but you can adjust individual filters after applying. See the [Headphone EQ guide](/guides/headphone-eq/) for customization options.
</Aside>
