Per-channel mute, solo, and dim controls with smooth fade transitions.

## Parameters

| Parameter | Type | Range | Default | Unit | Description |
|-----------|------|-------|---------|------|-------------|
| Enabled | Bool | On / Off | On | - | Master enable for mute/solo |
| Dim Gain | Float | -60 .. 0 | -20 | dB | Attenuation level when dimmed |
| Fade Time | Float | 0 .. 100 | 10 | ms | Mute/solo crossfade duration |
