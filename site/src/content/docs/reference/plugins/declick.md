Removes clicks, pops, and short transient defects from audio (vinyl restoration, recording artifacts).

## Parameters

| Parameter | Type | Range | Default | Unit | Description |
|-----------|------|-------|---------|------|-------------|
| Enabled | Bool | On / Off | On | - | Enable time-domain click repair |
| Sensitivity | Float | 1 .. 100 | 10 | - | Click detection sensitivity; lower values detect more clicks |
