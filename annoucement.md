SotF 0.5.11-beta is out.

What is SotF? For now, the stable part consist of:
- a roomeq system (measurement and optimisation)
- an audio player with plugins
- the optimisation also can optimise you headphone or anechoic speaker measurements.

What make it different?
- 100% open source
- multiplatform (MacOS, Windows, Linux)
- a full set of plugins from classical to advanced (upmixer, denoiser, binaural, mb-expander, mb-compressor, mono2stereo, crosstalk cancellation, ...)
- a hopefully not too complicated way to use all this plugins
and a lot more is coming at various state of maturity with the next large one being a system wide mixer for macos (with the same plugins).

What can it do today:
- record your speakers
- build a roomeq system and insert it into the player so you can test it live.
- play music :)

What does room EQ support today?
- stereo up to large number of speakers (tested with my 5.1.4)
- support for various subwoofers configuration: cardiod, MSO, DBA
- support for multi driver speakers
