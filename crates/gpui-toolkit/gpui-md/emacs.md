command to be supported with shortcut

ctrl-a               cursor jump to beginning of line
ctrl-b               cursor jump one character back across lines if necessary
ctrl-d               delete 1 character
ctrl-e               cursor jump to end of line
ctrl-f               cursor jump one character front across lines if necessary
ctrl-l               text align to middle of screen
ctrl-p               cursor jump one line up (same offset if possible and if not end of previous line)
ctrl-r pattern       search backward (cursor move as you search letter by letter)
ctrl-s pattern       search forward (cursor move as you search letter by letter)
ctrl-n               cursor jump one line down (same offset if possible and if not end of previous line)
ctrl-u 20 command    repeat 20 times command
ctrl-v               page down
ctrl-space           set mark at cursor
esc-b                back one word
esc-f                right one word
esc-<                start of document
esc->                end of document
esc-v                page up
esc-u                capitalize word on the right
ctrl-x ctrl-c        exit
ctrl-g               abort
ctrl-x ctrl-f        load file

esc-x command        execute command

goto-line            goto line
load-theme           load theme
dired                open directory viewer / file picker
