# math-solvers

High-performance linear solvers for BEM and FEM.

Iterative and direct linear solvers for numerical acoustics:
- Iterative: GMRES, BiCGSTAB, CGS, Conjugate Gradient
- Direct: LU decomposition
- Sparse: CSR matrix format
- Preconditioners: Jacobi, ILU
- Generic over scalar types (real and complex)
