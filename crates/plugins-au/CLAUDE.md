# plugins-au

Swift Audio Unit (AUv3) plugin wrapper for macOS.

## Purpose

Wraps the Rust plugin system (via `plugins-ffi`) into a macOS Audio Unit plugin that can be loaded by any AU host (Logic Pro, GarageBand, etc.).

## Platform

macOS only.

## Build

This is a Swift/Xcode project, not a Rust crate. Build with:

```bash
just build-au-swift    # Build Swift AU wrapper
just install-au        # Install to ~/Library/Audio/Plug-Ins/
just validate-au       # Run auval validation
```

## Dependencies

- `plugins-ffi` - Rust FFI bindings (static library + C headers)

## Notes

- The Swift code interfaces with Rust through C headers generated by `plugins-ffi`
- Must be validated with `auval` before distribution
