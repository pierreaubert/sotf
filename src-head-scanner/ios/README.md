# Head Scanner iOS App

Native iOS application for 3D head scanning and HRTF generation using ARKit and the Rust head-scanner library.

## Features

- **ARKit Integration**: Real-time 3D scanning using iPhone's TrueDepth camera and LiDAR
- **Scan Guidance**: Visual feedback showing which head regions need scanning
- **Quality Metrics**: Live coverage, density, and quality indicators
- **SOFA Export**: Generate personalized HRTF files in SOFA format
- **Mesh Export**: Save 3D head models as OBJ files

## Requirements

- **Xcode 15+**
- **iOS 15.0+**
- **Device Requirements**:
  - iPhone with ARKit support (iPhone 6s and later)
  - Recommended: iPhone with LiDAR sensor (iPhone 12 Pro and later) for best results
- **Rust toolchain** with iOS targets installed

## Building

### 1. Install Rust iOS Targets

```bash
rustup target add aarch64-apple-ios
rustup target add aarch64-apple-ios-sim
rustup target add x86_64-apple-ios
```

### 2. Build Rust Library

```bash
cd src-head-scanner/ios
./build-rust.sh release
```

This creates:
- `Frameworks/libhead_scanner_device.a` - For physical iOS devices
- `Frameworks/libhead_scanner_sim.a` - For iOS simulator
- `Frameworks/HeadScannerFFI.h` - C header for FFI

### 3. Open in Xcode

```bash
cd src-head-scanner/ios
xcodegen generate  # If using XcodeGen
# OR
open HeadScanner.xcodeproj
```

### 4. Configure Signing

1. Open project settings
2. Select "HeadScanner" target
3. Set your Team and Bundle Identifier under "Signing & Capabilities"

### 5. Build and Run

Select your device or simulator and press Cmd+R to build and run.

## Architecture

### Rust Core (`src-head-scanner/`)

The Rust library provides:
- Computer vision pipeline (feature detection, tracking)
- 3D reconstruction (structure-from-motion)
- Mesh generation (Delaunay triangulation, convex hull)
- SOFA generation (analytical HRTF + optional BEM solver)
- Scan guidance (coverage tracking, quality metrics)

### Swift UI Layer

The iOS app provides:
- ARKit integration for camera and depth capture
- Real-time frame processing
- SwiftUI interface with guidance overlays
- File management and export

### FFI Bridge

The `ffi.rs` module exposes C-compatible functions that Swift can call:
- `scanner_new()` / `scanner_free()` - Lifecycle management
- `scanner_process_frame()` - Process camera frames
- `scanner_get_guidance()` - Get scan guidance
- `scanner_generate_sofa()` - Export HRTF files

## Usage

1. **Launch App**: Open Head Scanner on your iPhone
2. **Start Scanning**: Tap the "Start" button
3. **Follow Guidance**: The app shows which head region to scan next
   - Yellow indicator = current target region
   - Green indicator = region already scanned
4. **Monitor Progress**: Watch the coverage percentage increase
5. **Complete Scan**: When coverage reaches 90%+, scan automatically stops
6. **Save Results**:
   - Tap 📥 to save the 3D mesh (OBJ format)
   - Tap 🌊 to generate SOFA HRTF file
7. **Access Files**: Files are saved to the app's Documents directory
   - Use Files app to access and share

## Troubleshooting

### Build Issues

**Error: "Target not found"**
```bash
# Install missing targets
rustup target add aarch64-apple-ios
rustup target add aarch64-apple-ios-sim
rustup target add x86_64-apple-ios
```

**Error: "cbindgen not found"**
```bash
cargo install cbindgen
```

**Error: "Linking failed"**
- Make sure you're linking against the correct library:
  - Device: `libhead_scanner_device.a`
  - Simulator: `libhead_scanner_sim.a`

### Runtime Issues

**ARKit Error: "Session failed"**
- Check that device supports ARKit (iPhone 6s+)
- Grant camera permission in Settings

**Poor Depth Quality**
- Use a device with LiDAR sensor for best results (iPhone 12 Pro+)
- Ensure good lighting conditions
- Move slowly and steadily around the subject

**Low Coverage**
- Follow the guidance indicators
- Ensure full head is visible in frame
- Capture from multiple angles (front, sides, back, top)

## Development

### Debug vs Release Builds

**Debug** (faster compilation):
```bash
./build-rust.sh debug
```

**Release** (optimized):
```bash
./build-rust.sh release
```

### Modifying FFI

If you change the Rust FFI interface:

1. Update `src/ffi.rs`
2. Rebuild: `./build-rust.sh`
3. Update Swift wrapper in `HeadScannerBridge.swift` if needed
4. Rebuild Xcode project

### Testing on Simulator

- Simulator doesn't have ARKit depth sensors
- App falls back to estimated depth from feature points
- For real testing, use a physical device

## Performance Optimization

- **Frame Throttling**: Processes every 3rd frame to reduce CPU load
- **Background Processing**: Frame processing happens on a dedicated queue
- **Rust Optimization**: Release builds use `-O3` optimization
